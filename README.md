# CMRIT Alumni Portal Website

## About the Project

The CMRIT Alumni Portal is a web-based platform designed to strengthen connections between alumni, current students, and the institution.

The portal aims to provide a centralized space for discovering alumni achievements, exploring events, and accessing information about the alumni community.

## Features

* **Home Page:** Introduces the alumni portal and provides access to its main sections.
* **About Us:** Showcases alumni achievements, research contributions, and related information.
* **Events:** Provides information about alumni events, reunions, and other activities.
* **Alumni Directory:** Helps users explore the alumni community.
* **Contact Page:** Provides a way to contact the institution.
* **Login and Signup Pages:** Provide user interface pages for account access and registration.

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js-related backend components
